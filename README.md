# Native Animation Framework — Fallout 4 1.11.240 compatibility port

This repository contains an unofficial compatibility/source port of Native
Animation Framework (NAF) 1.0.14 for Fallout 4 runtime `1.11.240.0` and F4SE
`0.7.9`.

Original NAF was created by Snapdragon/Deweh. This project preserves that
work on the newer runtime; it is not the official upstream continuation and
does not claim ownership of Native Animation Framework.

## Installation model

This project is a DLL compatibility update, not a complete NAF repack.

1. Install the original NAF 1.0.14 package from Snapdragon's original Nexus
   page. That package remains the source for the original plugin, scripts,
   Scaleform menus, MCM configuration, XML data, and other assets.
2. Install F4SE 0.7.9 for Fallout 4 1.11.240.
3. Install Address Library for Fallout 4 1.11.240.
4. Replace only `Data/F4SE/Plugins/NAF.dll` with the compatibility DLL.

Do not remove the original NAF assets. In particular, the compiled menu SWFs
and `NAF.pex` are not generated by this C++ build.

## Requirements

- Original NAF 1.0.14
- Fallout 4 `1.11.240.0`
- F4SE `0.7.9`
- Address Library for runtime `1.11.240.0`
- Microsoft Visual C++ runtime

Optional integrations:

- LooksMenu 1.7.0.4 (or the previously validated 1.7.0.3 binary) is needed only for body morph support. When absent, NAF
  continues normally with morph operations disabled.
- Mod Configuration Menu is needed only for convenient hotkey configuration.
  Without MCM, the menu remains available through the console command
  `cgf "NAF.ToggleMenu"` or other Papyrus callers.
- OCBP is optional and is not a NAF requirement. Its absence does not disable
  body animation, Body Creator, or Studio.

## Compatibility and safety

The port intentionally supports only Fallout 4 `1.11.240.0`. Address Library
lookups are exact and fail closed. Hook sites and critical interfaces are
validated before use. `FreeUpAllMarkers` resolves through exact Address
Library ID `2202575` and retains masked entry validation.

LooksMenu validation runs only when `f4ee.dll` is loaded. The supported binary
must match an exact validated 1.7.0.3 or 1.7.0.4 SHA-256 and ABI profile; a missing or mismatched
LooksMenu disables only morph support.

## Known issue: LookAt Cam

LookAt Cam is retained as an upstream legacy feature. It can exhibit
orientation/order-sensitive behavior in some player scenes. Normal NAF
FreeCam is recommended for general camera movement. When using LookAt Cam,
enable and configure it before beginning the animation. If it behaves
incorrectly, disable it and use FreeCam.

## Troubleshooting

When reporting a problem, provide:

- `NAF.log`;
- the F4SE log when discovery or plugin loading fails;
- native crash-logger output for a crash;
- the exact Fallout 4, F4SE, and Address Library versions;
- installed optional integrations, especially the LooksMenu version.

Common failure categories include:

- a DLL built for the wrong Fallout 4 runtime;
- a missing or incorrect Address Library database;
- malformed animation XML or missing animation files;
- an unsupported or modified LooksMenu binary;
- Creator project-directory or filesystem write failures.

NAF deliberately rejects mismatched runtime interfaces rather than continuing
with approximate addresses.

## Building from source

Requirements:

- Visual Studio 2022 with Desktop development with C++ and the v143 toolset;
- CMake 3.20 or newer;
- vcpkg configured through `VCPKG_ROOT`, including the dependencies resolved by
  the project (`spdlog` and `libzippp`);
- Python 3 for the compatibility audit tools;
- initialized Git submodules.

Pinned dependency revisions for this release-candidate tree:

- CommonLibF4: `4f6bdd2096df4ebd9fa24170007a62e8a7a21af5`
- ik: `b1700d9ad080c82143e2fb83e2594604bee1b9bb`
- pugixml: `6909df2478f7eb092e8e5b5cda097616b2595cc6`

Configure with deployment disabled, then build Release x64:

```powershell
cmake -S f4se-plugin -B "../Codex Production Files/build-release-vs" `
  -G "Visual Studio 17 2022" -A x64 `
  -DCOPY_BUILD=OFF
cmake --build "../Codex Production Files/build-release-vs" --config Release
```

The DLL is produced at
`../Codex Production Files/build-release-vs/Release/NAF.dll`. See `PORTING.md` and the scripts
under `tools/` for the evidence ledger and compatibility audits.

## Distribution and source

The preferred end-user artifact is the replacement `NAF.dll`; users obtain the
original framework package from the upstream Nexus page. This repository does
not prepare or authorize a wholesale redistribution of the upstream release or
third-party animation packs. A separate DLL release may be hosted according to
the chosen host's permissions.

Compatibility source is hosted at
`https://github.com/LZB7/Native-Animation-Framework`, with the original
`https://github.com/Deweh/Native-Animation-Framework` repository retained as
the `upstream` remote.

Reproducibility note: this branch currently pins CommonLibF4 commit
`4f6bdd2096df4ebd9fa24170007a62e8a7a21af5`, which contains the accumulated AE
ABI/relocation corrections plus the 1.11.240 runtime constant. This new
dependency commit and the parent `port/1.11.240` branch remain local until
publication is separately authorized. Publish the dependency branch before
the parent branch so a public recursive clone can retrieve the pinned gitlink.
The `ik` and `pugixml` pins remain unchanged and publicly retrievable.
